MinoMasal: hangi OAuth istemcisi?

Google Cloud'daki iki tam Client ID'yi aşağıya yapıştırın. Bu sayfa tamamen yereldir; internete istek gönderemez. Client Secret veya token girmeyin.

İki kimlik girildiğinde kontrol dosyası hazırlanacak.

İndirilen minomasal-client-check.json dosyasını sohbete ekleyin. Tam Client ID'ler dosyaya konmaz; yalnız rastgele nonce ve bu isteğe özel eşitlik kanıtları bulunur. API anahtarı, Client Secret, erişim veya refresh tokenı kullanılmaz, özetlenmez veya gönderilmez. GitHub tarafında yalnız mevcut Client ID ile eşitlik ve mevcut token/istemci çiftinin geçerliliği kontrol edilecek. Secret değişikliği, yeni token üretimi, iptal veya yayın yapılmayacak. Aynı sayı ile başlayan kimlikler aynı istemci demek değildir.
