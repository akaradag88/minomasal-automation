
# MinoMasal Müzik Kütüphanesi

Bu klasör hikâyelerde kullanılacak arka plan müziklerini içerir.

Planlanan dosyalar:

- intro.mp3 — Büyülü başlangıç
- happy.mp3 — Neşeli sahneler
- mystery.mp3 — Merak ve gizem
- emotional.mp3 — Duygusal sahneler
- ending.mp3 — Mutlu son

Müzikler anlatıcı sesini bastırmayacak şekilde kullanılacaktır.
